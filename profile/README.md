# Tessera Labs

Open-source tools for certificate authentication and Unix access management.

Our development has moved to [SourceCraft](https://sourcecraft.dev/tessera-labs).

## Open-source projects

- [Tessera](https://sourcecraft.dev/tessera-labs/tessera) — X.509 certificate authentication for Linux PAM, using hardware tokens or PKCS#12 credentials.
- [Census](https://sourcecraft.dev/tessera-labs/census) — declarative provisioning of Unix role accounts, groups, sudo rules and systemd limits. Census runs outside the authentication path.
